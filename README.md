# Code for [adaptiveedgetech.com](https://adaptiveedgetech.com)

## Technologies
- Typescript
- NextJS
- Tailwind CSS
- Sanity (for blog)?

## Local development
### Requirement
You need:
- node 14.6 or newer as a minimum, but we recommend 18 
- yarn

### Getting started
After cloning the repository, run `yarn` to install dependencies then `yarn dev` to run.

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
